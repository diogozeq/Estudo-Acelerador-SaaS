Coloque aqui a imagem anexada (pixel art do DeLorean).

Passos:
1) Salve a imagem anexada pelo chat como "delorean.png".
2) Mova ou copie o arquivo para: public/images/delorean.png
   Exemplo de nome completo no Windows:
   c:\Users\USUARIO\Desktop\FIAP\Projetos Pessoais\Estudo Acelerador SaaS\public\images\delorean.png
3) Reinicie o servidor de desenvolvimento se necessário (por exemplo: `pnpm dev`, `npm run dev` ou `yarn dev`).

Depois disso, a página `DeLorean` estará exibindo a imagem em `/images/delorean.png`.
